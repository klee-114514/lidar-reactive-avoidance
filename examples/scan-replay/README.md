# 扫描回放示例使用说明

本目录保存几组固定雷达输入，用于人工检查不同 MCU 或 FPGA 实现是否能得到相似的方向选择和状态转移。

这些文件不是自动测试程序，也不表示已经在真实车辆上验证通过。

## 1. 文件格式

文件扩展名虽然是 `.csv`，但目前采用“键值行 + 一行扇区数据”的文本格式。

以 `#` 开头的行是场景说明，不参与解析。

主要字段如下：

| 字段 | 含义 |
|---|---|
| `name` | 场景名称 |
| `front_mm` | 正前净空，单位 mm |
| `left_mm` | 左侧垂直净空，单位 mm |
| `right_mm` | 右侧垂直净空，单位 mm |
| `heading_deg` | 当前航向，单位度 |
| `scan_valid` | 扫描是否有效，1 有效，0 无效 |
| `front_lost` | 当前圈是否没有正前障碍段 |
| `expected_state` | 人工期望进入的状态 |
| `expected_side` | 初始选边期望，`left` 或 `right` |
| `expected_reason` | 期望的失败或回线退回原因 |
| `bins` | 72 个逗号分隔的距离值，单位 mm |

`bins` 的约定：

- 第 `0` 个值为车头正前；
- 每格增加 5°；
- 正角度方向为车辆左侧；
- 第 `18` 格为车正左；
- 第 `54` 格为车正右；
- `65535` 表示无有效回波。

必须确保 `bins` 正好包含 72 个值。

## 2. 示例场景

| 文件 | 用途 |
|---|---|
| `01-open-field.csv` | 空旷区域，不应触发避障 |
| `02-centered-box.csv` | 正前方居中障碍，检查左右选边 |
| `03-obstacle-left.csv` | 障碍偏左，检查是否选择右侧绕行 |
| `04-obstacle-right.csv` | 障碍偏右，检查是否选择左侧绕行 |
| `05-no-safe-direction.csv` | 四周过近，检查是否进入失败停车 |
| `06-return-blocked.csv` | 回线入口被堵，检查是否退回边界跟随 |

## 3. 使用方法

1. 选择一个场景文件。
2. 按行读取 `key=value` 字段。
3. 把 `bins` 按逗号拆分成 72 个整数。
4. 把其他字段填入 `lra_platform_snapshot_t`。
5. 让这些数据经过 MCU 适配层并调用 `lra_adapter_tick()`。
6. 对照控制器的状态、选边和失败原因。

输入与适配层的对应关系：

| 文件字段 | 平台快照字段 |
|---|---|
| `bins` | `bins[72]` |
| `front_mm` | `front_mm` |
| `left_mm` | `left_mm` |
| `right_mm` | `right_mm` |
| `heading_deg` | `heading_deg` |
| `scan_valid` | `scan_valid` |
| `front_lost` | `front_lost` |

第一次运行时可以设置：

```text
scan_done = 1
heading_valid = 1
travel_delta_mm = 0
step_done = 0
stall = 0
```

`scan_done` 是单圈完成事件，后续控制周期应恢复为 `0`。

## 4. 特殊场景

`06-return-blocked.csv` 表示控制器已经进入回线准备阶段时收到的扫描数据。

如果从空闲状态直接加载这个文件，控制器不会自动知道“当前正在准备回线”。

使用该场景时，需要先通过前面的运动步骤把控制器带入回线入口，或者在测试桩中直接设置对应状态。

## 5. 创建自己的回放数据

建议录制原始雷达数据后，按一整圈归约为 72 个扇区，再填写其他输入字段。

创建步骤：

1. 固定车辆位置和航向。
2. 记录一圈完整雷达数据。
3. 按 5° 计算每个扇区的最小距离。
4. 测量正前、左侧和右侧的垂直净空。
5. 记录当前航向、扫描有效性和正前障碍状态。
6. 填写人工期望结果。

不要用单个瞬时点代替整圈扫描。

不要把不同时间采集的扇区拼接成同一圈数据。

## 6. 结果判读

重点比较：

- 是否在预期位置触发避障；
- 选择的绕行侧是否符合预期；
- 是否错误地报告“无安全方向”；
- 回线入口被堵时是否退回跟随；
- 无效扫描是否立即停车。

如果移植结果与示例不一致，应先检查角度方向、左右正负、距离单位和 72 扇区映射，再检查车辆几何参数。
